Honesty states — designed, not handled

The engines refuse to fake precision; the UI treats each refusal as a first-class screen state with the engine's own words. These are features, not error handling.

Comp set has no closed sales
NONE SOLD — do not base an ARV on this comp set.
Confidence can never rise above "low" without closed sales. The scream renders on the band card itself.
Subject outside the comp size band
Every comp fell outside the size band — widen the set, not the band.
Verified live: a 1,613 SF subject vs 5,000 SF comps is refused, verbatim, in the error banner.
